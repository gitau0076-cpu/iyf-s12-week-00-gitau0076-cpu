## Steps to make a commit in git
 1. Run `git add`. Stages all modified, new, or deleted.
  2. Run `git commit -m "first Commit"`Takes all staged changes and saves them as a new snapshot.
   3. Run `git push -u origin main`Uploads local branch`.
   4. Run `git status`Displays the state of the working directory and staging area.
